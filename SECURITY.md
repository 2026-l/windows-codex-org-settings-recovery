# Security and privacy

## Public reports

Do not post raw logs, backup JSON, screenshots with account details, or unredacted command output. Remove usernames, profile paths, email addresses, tokens, workspace names, organization identifiers, conversation identifiers, and private project data.

This repository's scripts do not request administrator rights, credentials, authentication codes, or tokens. Stop if a modified copy asks for any of them.

## Vulnerabilities

For a vulnerability in this project, open a GitHub security advisory if that feature is available for the repository. Do not publish secrets or a working exploit in a public issue.

For vulnerabilities in OpenAI products, follow OpenAI's official security reporting process rather than this repository's issue tracker.
