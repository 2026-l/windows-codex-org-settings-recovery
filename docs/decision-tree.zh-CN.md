## 为什么必须重启后再验证

Windows 进程从父进程继承环境变量。在某个 PowerShell 进程内清除变量，并不会改变已经持有旧环境的 Explorer。继续从该 Explorer 启动应用，仍可能继承旧值。重启 Windows 才能建立干净的环境继承链。

## 不适用的情况

出现以下情况时，不要强行使用本修复：

- 用户级和机器级变量已经为空；
- 该变量由管理员有意配置；
- 应用只在 WSL 模式下失败；
- 日志明确指向网络策略、代理、登录或运行时故障；
- 问题发生在移动应用数据或修改包文件之后。

相同界面提示只是通用启动拦截，并不对应唯一根因。
